نصب نسخه PWA برنامه Mannismann Pipe 2.7 (ویندوز / اندروید / آیفون)
===============================================================
PWA یعنی برنامه از طریق مرورگر نصب می‌شود و آیکون مستقل، پنجره مستقل و حالت آفلاین دارد.
شرط امنیتی مرورگرها: صفحه باید روی آدرس HTTPS باشد (باز کردن مستقیم فایل از روی دیسک نصب‌پذیر نیست).

مرحله 1 - بارگذاری (یک بار، رایگان)
  کل محتوای این پوشه را روی یکی از سرویس‌های HTTPS آپلود کنید:
  - Netlify (Deploy manually: پوشه را drag & drop کنید) یا Cloudflare Pages یا GitHub Pages
  - فایل _headers هدرهای امنیتی (CSP، HSTS و ...) را روی Netlify/Cloudflare اعمال می‌کند.
  - فایل‌ها را داخل زیرپوشه یا ریشه سایت بگذارید؛ هر دو کار می‌کند.

مرحله 2 - نصب
  ویندوز (Edge یا Chrome): آیکون Install در انتهای نوار آدرس > Install
        یا منو ⋯ > Apps > Install this site as an app
  اندروید (Chrome): منو ⋮ > Install app  (یا Add to Home screen)
  آیفون/آیپد (Safari): دکمه Share > Add to Home Screen
        (در iOS فقط Safari امکان نصب دارد.)

به‌روزرسانی: فایل‌های جدید را روی همان آدرس جایگزین کنید؛ برنامه خودش نسخه جدید را می‌گیرد.
حریم خصوصی: برنامه هیچ داده‌ای به سرور ارسال نمی‌کند و هیچ منبع خارجی (فونت، اسکریپت) بارگذاری نمی‌کند.
